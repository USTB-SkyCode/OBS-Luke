# OBS-Luke

OBS Lecture Recording Script  
OBS录课妙妙脚本(自动在电脑屏幕与外置摄像头之间切镜头)

## activity-scene-switch.lua

### 功能介绍

- 每隔一段时间采样一次系统范围内的鼠标和键盘输入空闲时长，距最后一次输入不足 X 秒即视为“回来”，切换到**活跃场景**。
- 无操作持续 X 秒，视为“离开”，切换到**离开场景**。可选开启屏幕变化检测，若屏幕画面仍在持续变化则会阻止“离开”。

### 安装与使用

1. 打开 OBS → 工具 → 脚本 → “+”，选择本目录里的 `activity-scene-switch.lua`。
2. 在脚本设置里选择（或输入）活跃场景与离开场景，按需调整各项数值。
3. 关闭设置窗口即可生效，加载日志与每次切换都会写进“脚本日志”。

### 设置项

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| Active scene (recent input) | 空 | “回来”时切换到的场景 |
| Away scene (no input) | 空 | “离开”时切换到的场景 |
| Check interval (seconds) | 0.2 | 采样间隔 |
| Activity window (seconds) | 0.4 | 距最后一次输入小于该值视为“回来” |
| Idle time before away (seconds) | 10 | 无操作持续多久算“离开” |
| Screen change detection (prevents the away state) | 开 | 画面变化会阻止“离开” |
| Screen capture area | Primary monitor | 对比的画面区域；另一个值是 All monitors |
| Screen compare interval (seconds) | 1 | 画面对比间隔（0.5–60） |
| Screen change threshold (bits of 64) | 6 | dHash 汉明距离达到该值算“画面在变” |

### 行为细节

- **只在状态翻转时动作**：脚本只在“离开 → 回来”和“回来 → 离开”两个时机切换场景，不纠正你手动切换的场景；手动切走后，下一次状态翻转时脚本才重新接管。
- **两档阈值之间无判定**：空闲时长处于“活动窗口”和“离开时间”之间时状态保持原样，不会来回抖动。
- **画面变化只阻止“离开”**：可选功能，开启后“离开”要求输入与画面同时安静；画面变化不会切回活跃场景，避免离开场景是动画时来回振荡。
- **持续画面对比**：开启后只要不处于离开状态，就按对比间隔持续截图，随时刷新“画面安静多久”的计时；只有离开状态期间暂停，回来后重取一次基线。截图只留在内存里，不落盘（主显示器约 20ms/次、全部显示器约 100ms/次）。
- **加载时不评估**：脚本加载后只把当时观察到的状态记进状态机（不切场景），之后的第一次状态翻转才开始自动切换。若加载时你已离开，回来时会切到活跃场景。
- **场景缺失**：配置的场景在当前场景集合里不存在（被删、改名或换了场景集合）时，跳过本次切换并在日志里警告，不做猜测；场景恢复存在后，下一次状态翻转即可正常切换。
- **转场**：使用 OBS 当前的转场。工作室模式（双屏预览）下会直接切节目画面，观众可见。
- **场景查找**：按名称在当前场景集合中查找；设置里的下拉列表只是便利，允许手动输入。
- **配置校验**：采样间隔不小于活动窗口、或活动窗口不小于离开时间时，脚本会在日志里给出警告。

### 已知限制

- 仅支持 Windows（依赖 `user32.GetLastInputInfo`）。
- 手柄原生输入不算“操作”；但被 Steam Input / DS4Windows / reWASD 等映射成鼠标键盘的输入会被算作操作。
- 长按鼠标键并保持不动时不会产生新的输入事件，超过阈值会被判为“离开”（键盘长按有自动重复事件，不受影响）。
- 锁屏（Win+L）与 UAC 安全桌面上的输入可能不计入当前会话，效果上等于“锁屏即离开”。
- 判定是系统级的：任何程序（包括自动化工具、远程桌面注入）产生的输入都会刷新计时，无法区分输入发生在哪个窗口。
- 轮询跑在 OBS 图形线程的帧 tick 上，检查间隔是“至少多久”而不是精确定时（一般有一个视频帧的误差）。
- 屏幕变化检测依赖桌面级 GDI 截图：独占全屏游戏、HDR 输出下可能黑屏或偏色，检测会失效（输入检测不受影响）。
